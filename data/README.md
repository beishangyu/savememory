# 词库文件

这三个文件可以直接粘贴到应用的「导入 → 批量词表」里：

| 文件 | 词条数 | 说明 |
| --- | --- | --- |
| `cet4.txt` | 4500 | 大学英语四级核心词汇 |
| `cet6.txt` | 4008 | 大学英语六级核心词汇 |
| `kaoyan.txt` | 5000 | 考研英语核心词汇 |

格式为每行 `单词 - 释义`：

```
abandon - 丢弃；放弃；抛弃
ability - 能力；能耐；本领
```

## 它们也是应用的内置词库

「导入 → 内置词库」面板里可以直接一键导入这三个词表 —— 新用户不用自己去别处找词表。

技术上用的是 Vite 的 `import.meta.glob(..., { query: '?raw' })`：

- 三个词表各自打成一个**独立的懒加载 chunk**，主包不会因此变大；
- Service Worker 会预缓存这三个 chunk，所以**装好后离线也能用**；
- 用户点哪一份才下载哪一份的原始文本（首次访问后浏览器缓存）。

面板上还有一个「导入后生成卡片」的勾选框：**由用户决定**这份词表是变成可复习的卡片，
还是只作为材料存进「卡片库」当参考。

## 怎么用（手动粘贴）

1. 打开应用 → 「导入」页。
2. 把文件内容整份粘贴进「批量词表」输入框。
3. 输入框下方会显示「已识别 N 条」，确认数量无误。
4. 点「解析并生成卡片」。

「生成双向卡片」默认开启，所以每个词条会生成 **英→中** 与 **中→英** 两张卡。
4500 词的词表大约会生成 9000 张卡片，建议先关掉双向、熟悉节奏后再开。

## 清洗规则

词表由 `scripts/build-wordlists.mjs` 生成（`npm run wordlists`），清洗规则：

- 去掉 HTML 标签、音标（`[əˈbændən]`）、词性标记（`n.` / `vt.` / `adj.` …）。
- 只保留第一个义项，多义项的释义用 `；` 连接。
- 去掉释义里的**逗号**、**冒号**、**破折号** —— 这些是应用的导入分隔符，
  留在释义里可能被误判。顿号 `、` 和分号 `；` 是安全的，照常保留。
- 去掉重复词条，按字母顺序排序。
- 释义最长 36 个字，超出的在义项边界截断。

## 数据来源

全部来自公开的开源词库项目：

| 来源 | 用途 |
| --- | --- |
| [mahavivo/english-wordlists](https://github.com/mahavivo/english-wordlists) | 四级大纲词表、六级词表、考研词表（`NPEE_Wordlist.txt`）、COCA 词频序、柯林斯星级词频 |
| [hehonghui/en_dict](https://github.com/hehonghui/en_dict) | 六级词表（第二来源，用于补全释义） |
| [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) | 四级 / 六级 / 考研词表（`词\t释义` 格式） |

### 「核心」是怎么选出来的

原始词库动辄七八千到一万词，直接导入太重。每个词有两个频率信号：

1. **柯林斯星级**（5★ 最常用，来自 `柯林斯词频-5星至0星.xlsx`）——
   这是中文学习者最常用的分级口径。
2. **COCA 词频序**（`COCA_20000.txt`）—— 当两个词星级相同时，用语料库频次决定先后。

先按星级降序、再按 COCA 频次升序排序，取前 N 个（4500 / 4800 / 5000）。
六级词库本身只收录了 4008 个不重复的词，因此六级文件略少于另外两个。

## 重新生成

```bash
npm run wordlists
```

下载的文件缓存在 `.cache/wordlists/`，重跑不会重复下载。
如果网络不通，直接用仓库里已有的 `data/*.txt` 即可 —— 它们已经是成品。

脚本只依赖 Node 内置模块（`fetch` / `zlib`），没有额外依赖：
GitHub 的 tarball 由 `codeload.github.com` 提供，xlsx 用内置的 zip + inflate 解析。
